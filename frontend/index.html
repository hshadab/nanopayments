Architectural placement — where Preflight fits

Drop-in. Adopting Preflight requires no changes to your existing Circle Agent Wallet or Turnkey configuration. The proof rides as an HTTP header alongside the existing x402 payment signature. Sellers verify with one public endpoint call.
Why Arc. Per-API-call nanopayments are only economic on a chain with deterministic finality, predictable sub-cent USDC-denominated fees, and agent-native throughput (pre-funded Gateway, no per-call settlement round trip). Arc gives all three. The proof-gated path also makes every blocked attempt a zero-settlement-cost exit — UNSAT never produces a signature, so Arc's throughput is never burned on bad intents.
